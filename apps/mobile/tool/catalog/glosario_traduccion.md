# Glosario para traducir el catálogo de ejercicios (inglés → español de México)

Estilo: español neutro de México, segunda persona del singular (tú), imperativo
("Acuéstate", "Sujeta", "Baja"). Frases claras y naturales, no literales.
Conserva números, grados, repeticiones y segundos tal cual.

Equipo
- barbell → barra · dumbbell → mancuerna · kettlebell → pesa rusa
- cable / pulley → polea (low pulley → polea baja, high pulley → polea alta)
- machine → máquina · Smith machine → máquina Smith · bench → banco
- e-z curl bar / EZ bar → barra Z · rope attachment → cuerda
- bands / resistance band → banda elástica · medicine ball → balón medicinal
- exercise ball / stability ball → pelota de ejercicio · foam roll → rodillo de espuma
- plate → disco · rack → rack · handle → maneral · bar → barra
- body only / bodyweight → peso corporal

Movimientos
- press → press · bench press → press de banca · incline → inclinado · decline → declinado
- flat → plano · fly / flye → aperturas · crossover → cruce · row → remo
- pulldown → jalón · pull-up → dominada · chin-up → dominada supina · dip → fondo
- curl → curl · hammer curl → curl martillo · preacher curl → curl predicador
- extension → extensión · skull crusher → press francés · kickback → patada
- squat → sentadilla · front squat → sentadilla frontal · hack squat → sentadilla hack
- lunge → desplante · split squat → sentadilla búlgara (solo si es Bulgarian) o desplante fijo
- deadlift → peso muerto · Romanian deadlift → peso muerto rumano · stiff-legged → con piernas rígidas
- good morning → buenos días · hip thrust → empuje de cadera (hip thrust)
- glute bridge → puente de glúteo · leg press → prensa de piernas
- leg curl → curl de pierna · leg extension → extensión de cuádriceps
- calf raise → elevación de talones · shrug → encogimiento de hombros
- lateral raise → elevación lateral · front raise → elevación frontal
- rear delt / reverse fly → pájaros · face pull → face pull
- upright row → remo al mentón · military press / overhead press → press militar
- crunch → abdominal (crunch) · sit-up → abdominal completo · plank → plancha
- stretch → estiramiento · clean → cargada · snatch → arrancada · jerk → envión

Agarre y posición
- grip → agarre · overhand / pronated → prono · underhand / supinated → supino
- neutral grip → agarre neutro · close grip → agarre cerrado · wide grip → agarre abierto
- medium grip → agarre medio · shoulder width → al ancho de los hombros
- starting position → posición inicial · repetitions → repeticiones · set → serie
- exhale → exhala · inhale → inhala · contraction → contracción

Músculos (si aparecen en el texto)
- chest → pecho · lats → dorsales · traps → trapecio · glutes → glúteos
- hamstrings → isquiotibiales (femorales) · quadriceps → cuádriceps · calves → pantorrillas
- abs / abdominals → abdomen · lower back → zona lumbar · forearms → antebrazos
